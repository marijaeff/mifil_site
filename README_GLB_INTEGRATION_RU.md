# MiFiL - возврат акварельной версии + вставка нового GLB-дома

Что внутри:
- восстановлена акварельная домашняя страница в духе версии до A-frame-экспериментов;
- вставлен новый 3D-дом `assets/MiFiL_Aframe_Dream_House_v1.glb`;
- старый процедурный `js/house.js` заменён на просмотрщик GLB;
- сохранены:
  - список проектов слева,
  - page.html со страницами проектов,
  - мобильные подписи окон,
  - стрелки поворота,
  - переходы к проектам,
  - отдельная страница Playable Letter.

## Важно

Для показа GLB на главной используется Three.js и GLTFLoader через CDN.
Поэтому:
- открывай проект через локальный сервер или обычный хостинг,
- не через `file://`.

Например:
- VS Code Live Server
- `python -m http.server`
- GitHub Pages / Netlify / Vercel
