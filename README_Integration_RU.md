# MiFiL — интеграция Playable Letter

Установка: поверх текущей версии MiFiL v6.3.

1. Сохрани резервную копию сайта.
2. Распакуй содержимое архива в КОРЕНЬ сайта MiFiL, согласившись на замену `index.html` и `page.html`.
3. Папка `playable-letter/` должна оказаться рядом с `index.html`, а не внутри `assets` или `js`.
4. На сайте открой главную и нажми на Playable Letter в списке либо на окно проекта у 3D-дома.
5. На внутренних страницах остальных проектов ссылка Playable Letter также ведёт на новую страницу.
6. Если раньше использовался `page.html?view=playable-letter`, этот адрес автоматически переадресует на `playable-letter/`.

### Что мы сохранили

- Исходный дизайн лендинга V2, все блоки, изображения, примеры игры, видео, выбор оформления, FAQ и форму брифа.
- Основной 3D-дом, остальные приложения, 16 языков главного сайта, мобильные подписи окон и оформление MiFiL не менялись.
- Английский язык исходного лендинга (перевод остальных языков туда не добавлялся).

### Минимальная адаптация

- Заменены внешние ссылки на MiFiL (`https://mifil.me/`) на относительные (`../index.html`) — корректно работает и в тестовой папке / подпапке сайта.
- На телефоне добавлена явная ссылка `← Home` в шапке, без изменения цветовой палитры и остальных элементов дизайна.
- Добавлена иконка MiFiL из основного сайта в браузерную вкладку.

### Перед публикацией продаж

`playable-letter/config.js` пока содержит пустые значения `demoUrl`, `orderUrl`, `priceAndDelivery`.
Сейчас форма только генерирует текст брифа на устройстве, сама ничего не отправляет и не принимает оплату.
Необходимо добавить реальные ссылки, цену/сроки, проверить доступность демоверсии и юридические тексты до начала продаж.
Изображённые QR-коды в превью являются иллюстрациями.

Проект можно проверить локально через VS Code Live Server.
