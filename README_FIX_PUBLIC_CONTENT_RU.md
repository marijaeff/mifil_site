# MiFiL — исправление публикации текстов (v2)

Этот патч исправляет обновление опубликованных текстов на страницах `page.html` и добавляет диагностику загрузки Firestore.

## Что исправлено

- На `page.html` не был подключён файл `assets/project-status.js`. Старый `firebase/site-content.js` проверял его наличие и **прерывал применение всех данных из Firestore**, поэтому страницы «О MiFiL», «От создателя», «Конфиденциальность» продолжали показывать старые тексты. Теперь статусы подключаются, а тексты могут применяться независимо от них.
- На публичном сайте чтение `siteContent/public` выполняется непосредственно с сервера, чтобы не показывать старый кэш Firestore после обновления страницы.
- Добавлена диагностика `?cmsDebug=1`, которая показывает, были ли загружены опубликованные данные или использованы локальные тексты.
- В редакторе подписано, что поле `intro` пока не используется на главной, а при редактировании страниц показывается выбранный язык и ссылка на проверку.
- Добавлены номера версий скриптов, чтобы старые файлы реже оставались в браузерном кэше.

## Как установить

1. Сохрани копию текущего сайта.
2. Распакуй содержимое ZIP **в корень сайта**, сохраняя структуру папок и заменяя одноимённые файлы.
3. **Не заменяй `firebase/config.js`** — здесь его нет намеренно, чтобы сохранить твои настройки Firebase.
4. Опубликуй изменённые файлы на своём хостинге (например, через GitHub Pages).
5. Открой страницу в приватном окне браузера либо обнови её через Ctrl+Shift+R.

## Как проверить

1. В админке зайди в «Страницы» → выбери русский язык → измени текст «О MiFiL» на узнаваемую фразу → «Опубликовать» (подтверди публикацию).
2. В админке появится ссылка «Проверить опубликованную страницу». Она открывает `page.html?view=about&lang=ru&cmsDebug=1`.
3. В нижнем углу сайта должно появиться сообщение **«Опубликованные данные загружены из Firestore»**. Если вместо этого показано **«Используются локальные тексты»**, там будет указана причина (например, ошибка доступа Firestore или отсутствие публикации).
4. Если сообщение говорит об успешной загрузке, но текст старый — убедись, что изменяешь именно тот язык и то поле, которые отображаются на открытой странице. Поле `intro` сейчас не видно на главной.

Для главной страницы диагностика открывается по адресу `index.html?cmsDebug=1` или `index.html?lang=ru&cmsDebug=1`.

**Важно:** повторный импорт содержимого не нужен. Не удаляй `siteContent/public` и `siteContent/draft` — патч использует твою существующую базу и опубликованные данные.

Если ошибка остаётся, пришли мне текст из нижней диагностической панели и уточни, какой текст ты меняла: название проекта, описание, текст страницы или перевод.
