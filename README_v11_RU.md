# MiFiL v11: домик, растения и фонарь

Это **точечное обновление поверх MiFiL v10**. Продающую страницу Playable Letter, стили и переводы обновление не затрагивает.

## Что исправлено

- Перемещён книжный шкаф внутрь A-frame, чтобы полки и книги не пересекали скат крыши.
- Исправлены внутренние полочки в боковых окнах: они короткие, находятся внутри дома. Котику оставлена опора.
- Добавлено настоящее объёмное растение **на переднюю деревянную площадку**, справа. Больше нет растений, прорастающих через крышу.
- Фонарь поставлен **на ту же площадку слева**.
- Уменьшенный в v10 масштаб дома сохранён.
- Обновлены .glb, версия скрипта и резервная загрузка модели для локального `file://` просмотра.

## Куда копировать файлы

Распакуй архив в **корневую папку текущего сайта** с заменой `index.html` и `js/house.js`, сохраняя структуру `assets/`.

Изменённые/новые файлы:

- `index.html`
- `js/house.js`
- `assets/MiFiL_Aframe_Dream_House_v11.glb`
- `assets/house-data-v11.js`

Старый `assets/MiFiL_Aframe_Dream_House_v1.glb` можно пока оставить, он больше не используется этой версией. Сделай резервную копию сайта, затем после установки обнови страницу через Ctrl + Shift + R.

## Проверка

Новая геометрия GLB открыта программно и просмотрена с четырёх сторон в отдельном рендерере. WebGL в твоём браузере потребуется проверить на устройстве; тест рендерера не гарантирует идентичность отображения.
