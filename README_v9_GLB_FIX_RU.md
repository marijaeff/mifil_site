# MiFiL v9 — исправление GLB-дома

Это обновление подготовлено специально на основе присланного `mifil_site_2.zip`.

## Установка

1. Создай резервную копию текущего проекта.
2. Распакуй архив обновления **в корневую папку сайта**, туда, где уже лежат `index.html`, `script.js` и папка `assets`.
3. Согласись на замену существующих файлов.
4. Перезагрузи страницу с очисткой кэша (Ctrl+Shift+R / Cmd+Shift+R).

**Важное:** здесь НЕТ полного архива проекта: сохранены все неизменённые страницы,
включая `playable-letter/`.

## Что было сломано

Предыдущая интеграция использовала пути к `three.min.js` и `GLTFLoader.js`, которых
нет в указанной версии Three.js. Из-за ошибки исполнения браузер не мог загрузить
реальный GLB и показывал плоскую запасную SVG-картинку.

## Что исправлено

- Убраны зависимые от внешнего CDN подключения. Новый `js/house.js` непосредственно
  считывает геометрию, текстуры и материалы из действительного файла `.glb`
  через WebGL 1 (без сторонней 3D-библиотеки).
- Загрузка 3D теперь отслеживается: запасная картинка скрывается только при
  успешной загрузке модели.
- Для локального открытия `index.html` предусмотрен лениво загружаемый
  `assets/house-data.js`: он используется только там, где браузер блокирует
  чтение `.glb` через `file://`. На обычном хостинге модель загружается как `.glb`.
- Вместо грубого 2D-треугольника запасным изображением стала небольшая иллюстрация
  настоящей модели (только если WebGL не поддерживается).
- Возвращены мини-иллюстрации проектов, небольшие описания, автоповорот к окну
  при наведении с компьютера, точки-пагинация и стрелки.
- Продолжает работать текущая структура ссылок, включая `playable-letter/`.

## Проверка

Проверены синтаксис JavaScript, загрузка и разбор всех 89 мешей настоящего GLB,
материалы, четыре окна и обе ветки загрузки (обычный HTTP и блокировка file://).
Проверена процедура вызова рендера через тестовый WebGL-контекст.

**Ограничение:** в рабочей среде отключён аппаратный WebGL, поэтому полный
визуальный рендер в браузере не удалось подтвердить. Это следует проверить
на твоём устройстве после замены файлов. Если браузер отключает WebGL,
остаётся спокойное запасное изображение и доступны прямые ссылки на проекты.
