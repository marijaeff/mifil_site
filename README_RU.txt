MiFiL v13 - обновление иконок проектов

Устанавливать поверх MiFiL v12 (и любых последующих версий, в которых HTML списка проектов совпадает с v12).

Заменить в корне сайта:
 - index.html
 - assets/icon-playable-letter.png
 - assets/icon-livemo.png
 - assets/icon-our-quest.png
 - assets/icon-feel.png

Что меняется:
 - новые контрастные прозрачные PNG-иконки, подготовленные для маленьких размеров меню
 - обновлена версия в URL PNG, чтобы браузер не показывал старые файлы из кэша

Дом, 3D-модель, скрипты, шторы, языки, порядок проектов и другие страницы не менялись.
Перед заменой сохрани резервную копию index.html.
